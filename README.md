# ローマ字テーブルコンバーター
各IMEから出力できるローマ字テーブルのテキストファイルを別のIME向けに変換するツールです。
Google日本語入力、ATOK、CorvusSKKに対応します。

## セットアップ
このプロジェクトはKotlinで書かれており、Gradleを使用してビルドします。以下の手順でセットアップを行います。

1. プロジェクトをクローンまたはダウンロードします。
2. IntelliJ IDEAなどのIDEでプロジェクトを開きます。
3. Gradleを使用してプロジェクトをビルドします。
![image](https://github.com/polisherm/ImeRomanTableConverter/assets/53828920/fec1ba14-aec0-4e12-ad9d-10e157a1963a)


## 使用方法
1. アプリケーションを起動します。
2. [開く]ボタンをクリックして、既存のローマ字マップファイルを選択します。
3. 変換先を選択します。
4. 変換後のローマ字テーブルが生成され、保存ダイアログが表示されます。
5. 保存先とファイル名を指定して保存します。
